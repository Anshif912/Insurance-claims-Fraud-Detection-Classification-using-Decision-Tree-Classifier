# Insurance Claim Classification

## Project Description
A machine learning project that classifies insurance claims as valid or fraudulent using a Decision Tree Classifier.

## Objective
- Automate claim classification
- Detect fraudulent claims
- Improve decision-making efficiency

## Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Workflow
1. Data Preprocessing  
2. Exploratory Data Analysis  
3. Model Training (Decision Tree)  
4. Model Evaluation  

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## How to Run
pip install -r requirements.txt  
jupyter notebook  

## Future Scope
- Improve accuracy with advanced models
- Hyperparameter tuning
- Deployment as a web application
